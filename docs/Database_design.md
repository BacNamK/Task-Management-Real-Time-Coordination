# Cơ sở dữ liệu

## 1. Nghiệp vụ bảng

### 1.1 User & Session

    - User : Lưu trữ thông tin cơ bản người dùng.

    - Session : Lưu trữ thông tin phiên đăng nhập và token làm mới, duy trì trạng thái đăng nhập bỏa mật và xử lý đăng nhập / cấp lại token.

### 1.3 Workspace & Member

     - Workspace_member : bảng trung gian giữa `người dùng` và `workspace` và ghi nhận vai trò, giải quyết vấn đề một người có thể tham gia nhiều dự án.

    - Workspace : Không gian làm việc, mọi dữ liệu về bảng công việc và phòng chat đều thuộc về một workspace cụ thể.

### 1.4 Kanban Board

    - Board : bảng quản lý dự án công việc trong Workspace.

    - Column : các cột trạng thái công việc thuộc về một Board  ("To Do","Progress","Done"). Có thuộc tính order để sắp xếp thứ tự hiện thị cột.

    - Task : thẻ chi tiết công việc nằm trong Column.

### 1.5 Chat Room

    - Chat Room : kênh trao đổi thông tin trong workspace.

    - Chat Room Participant : quản lý danh sách thành viên tham gia vào từng phòng chat.

    - Message : thông tin cơ bản của message.

## 2. POSTGRESQL

```sql
CREATE EXTENSION IF NOT EXISTS pgcrypto;

CREATE TYPE "Role" AS ENUM (
    'ADMIN',
    'MEMBER'
);

CREATE TABLE "users" (
    "id" BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    "uuid" text NOT NULL UNIQUE DEFAULT gen_random_uuid(),
    "name" varchar NOT NULL UNIQUE ,
    "password" text NOT NULL,
    "email" varchar NOT NULL UNIQUE,
    "image" text
);

CREATE TABLE "session" (
    "id" BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    "user_id" bigint NOT NULL,
    "refresh_token" text,
    "created_at" TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP,
    "expired_at" TIMESTAMPTZ,
    CONSTRAINT fk_session_user
    FOREIGN KEY (user_id) REFERENCES users (id) ON DELETE CASCADE
);

CREATE TABLE "workspace" (
    "id" BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    "uuid" text NOT NULL UNIQUE DEFAULT gen_random_uuid(),
    "name" varchar NOT NULL,
    "slug" varchar NOT NULL UNIQUE
);

CREATE TABLE "workspace_member" (
    "id" BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    "uuid" text NOT NULL UNIQUE DEFAULT gen_random_uuid(),
    "workspace_id" bigint NOT NULL,
    "user_id" bigint NOT NULL,
    "role" "Role" DEFAULT 'MEMBER'
    CONSTRAINT fk_user_id FOREIGN KEY (user_id) REFERENCES users (id)
    CONSTRAINT fk_workspace_id FOREIGN KEY (workspace_id) REFERENCES workspace (id)
);

CREATE TABLE "board" (
    "id" BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    "name" varchar,
    "workspace_id" bigint NOT NULL
    CONSTRAINT fk_workspace_id FOREIGN KEY (workspace_id) REFERENCES workspace (id)
);

CREATE TABLE "column" (
    "id" BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    "name" varchar,
    "order" int,
    "board_id" bigint NOT NULL
    CONSTRAINT fk_board_id FOREIGN KEY (board_id) REFERENCES board (id)
);

CREATE TABLE "task" (
    "id" BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    "title" varchar NOT NULL,
    "description" text,
    "order" int,
    "due_date" timestamp,
    "column_id" bigint NOT NULL,
    "creator_id" int NOT NULL,
    "assignee_id" int NOT NULL
    CONSTRAINT fk_column_id FOREIGN KEY (column_id) REFERENCES column (id)
    CONSTRAINT fk_creator_id FOREIGN KEY (creator_id) REFERENCES users (id)
    CONSTRAINT fk_assignee_id FOREIGN KEY (assignee_id) REFERENCES users(id)
);

CREATE TABLE "chat_room" (
    "id" BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    "uuid" text NOT NULL UNIQUE DEFAULT gen_random_uuid(),
    "name" varchar NOT NULL,
    "is_direct" boolean DEFAULT false,
    "workspace_id" bigint NOT NULL
    CONSTRAINT fk_workspace_id FOREIGN KEY (workspace_id) REFERENCES workspace (id)
);

CREATE TABLE "message" (
    "id" text NOT NULL UNIQUE DEFAULT gen_random_uuid(),
    "content" text,
    "created_at" timestamp DEFAULT (now()),
    "sender_id" int NOT NULL,
    "room_id" bigint NOT NULL
    CONSTRAINT fk_room_id FOREIGN KEY (room_id) REFERENCES chat_room (id)
    CONSTRAINT fk_sender_id FOREIGN KEY (sender_id) REFERENCES users (id)
);

CREATE TABLE "chat_room_participant" (
    "id" text NOT NULL UNIQUE DEFAULT gen_random_uuid(),
    "chat_room_id" bigint NOT NULL,
    "user_id" bigint NOT NULL,
    CONSTRAINT fk_user_id FOREIGN KEY (user_id) REFERENCES users (id)
);

CREATE UNIQUE INDEX ON "workspace_member" ("workspace_id", "user_id");

CREATE UNIQUE INDEX ON "chat_room_participant" ("chat_room_id", "user_id");

COMMENT ON COLUMN "chat_room"."name" IS 'Null nếu là chat 1-1';

COMMENT ON COLUMN "chat_room"."is_direct" IS 'True nếu là chat cá nhân 1-1';
```

| Bảng cha           | Bảng con                | Quan hệ |
| ------------------ | ----------------------- | ------- |
| `users`            | `session`               | `1 - n` |
| `users`            | `workspace_member`      | `1 - n` |
| `users`            | `task`                  | `1 - n` |
| `users`            | `message`               | `1 - n` |
| `users`            | `chat_room_participant` | `1 - n` |
| `workspace_member` | `workspace`             | `1 - n` |
| `workspace`        | `board`                 | `1 - n` |
| `workspace`        | `chat_room`             | `1 - n` |
| `board`            | `column`                | `1 - n` |
| `column`           | `task`                  | `1 - n` |
| `chat_room`        | `chat_room_participant` | `1 - n` |
| `chat_room`        | `message`               | `1 - n` |
